📌 Project Overview

This project contains the User Interface (UI) design for the Automated Trash Collection Bot.
The UI is designed to provide a modern, interactive, and intuitive dashboard where users can:

Monitor the bot’s activity in real-time.

Check bin fill levels and battery status.

Receive alerts & notifications.

Control the bot manually when needed.

🎨 UI Features

📊 Dashboard View – Displays real-time data (battery, waste level, location).

🗑 Bin Status Indicator – Shows whether the trash bin is empty, half-full, or full.

🎮 Manual Control Panel – Buttons for movement (forward, backward, left, right, stop).

🔔 Notification System – Alerts for maintenance, full bin, or low battery.

🌐 Responsive Design – Works on both desktop & mobile screens.

🛠️ Built With

Figma / Adobe XD / Sketch (for UI mockups & design)

React.js / HTML / CSS / JavaScript (for implementation, if coded UI)

Icons & Assets – Material Icons, Lucide, or custom assets
